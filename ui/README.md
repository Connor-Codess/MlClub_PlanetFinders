# Planet Finders Galaxy

Interactive 3D map of the Kepler stars our model flags as planet hosts, placed in the Milky Way using Gaia distances.

Live link: enable GitHub Pages (Settings → Pages → Source: GitHub Actions); the workflow in .github/workflows/pages.yml publishes this folder.

- Scroll to zoom, left-drag to pan, right-drag to rotate.
- Green stars are held-out test stars (honest scores); purple stars were in training/validation (optimistic scores).
- Gold rings mark held-out stars where the model says "planet" but the catalog still says "candidate".
- Click a star to fly to it and see its folded light curve and planet probability.

Data files in `data/` are generated by `export_ui_data.py` in the main project.
Run locally: `python3 -m http.server 8765 --directory .` then open http://127.0.0.1:8765
